# Contributing

Open an issue before adding a feature.
Keep PRs under 300 lines of diff.
Use only the Python standard library, supporting Python 3.10+.
Keep the tool in `mcp_probe.py`.
Every new behaviour gets a reusable path under `paths/` that demonstrates it.
Update the usage skill and README when adding a subcommand.
Run the verification commands in `AGENTS.md`.
Never commit credentials or unmasked transcripts.
